# Развёртывание на Bothost.ru

Инструкция рассчитана на тариф **Базовый** и загрузку ZIP-архива.

## 1. Подготовьте панель

1. Откройте профиль Bothost и включите интерфейс **«Загрузка бота из архива»**.
2. Перейдите в **Мои боты → Загрузить из архива**.
3. Загрузите архив проекта `oleg_chat_bot_bothost.zip`.

В архиве уже есть `bot.py`, `requirements.txt`, `bothost.json`, `Dockerfile` и `Procfile`. В мастере укажите:

- **Название:** например `Олег — модератор чата`;
- **Платформа:** Telegram;
- **Главный файл:** `bot.py`;
- **Язык:** Python 3.11 или Авто.

Если панель предлагает использовать собственный Dockerfile, включите эту опцию. Для обычного Python-бота также подходит автоопределение по `bothost.json` и `requirements.txt`.

## 2. Добавьте секреты в переменные окружения

Откройте настройки созданного бота → **Переменные окружения** и добавьте значения приватно, не вставляя их в код:

```text
TELEGRAM_BOT_TOKEN=токен @Avkartbot
GROQ_API_KEY=ключ Groq
GROQ_MODEL=llama-3.3-70b-versatile
ALLOWED_CHAT_ID=числовой ID чата «Психика на минималках Чат»
DB_PATH=/app/data/oleg_bot.sqlite3
LOG_LEVEL=INFO
```

`ALLOWED_CHAT_ID` рекомендуется заполнить: тогда бот будет модерировать только нужный чат. Если оставить пустым, он будет работать во всех группах, где его добавили.

## 3. Persistent-хранилище

Включите persistent storage/данные для каталога:

```text
/app/data
```

Именно там хранится `oleg_bot.sqlite3` со счётчиками нарушений, уровнями наказаний и активными мутами. Без persistent-хранилища эти данные могут сброситься при пересборке контейнера.

## 4. Деплой и проверка

Нажмите **Задеплоить** и дождитесь окончания сборки. В логах должен появиться текст:

```text
Oleg bot started
```

Затем проверьте в чате:

```text
ОЛЕГ как дела?
```

Тестовое сообщение бот сам не отправляет.

## 5. Права Telegram

`@Avkartbot` должен быть администратором чата с правами:

- удаление сообщений;
- блокировка пользователей;
- ограничение пользователей.

Privacy Mode в BotFather должен быть отключён.

## 6. Обновление

Для обновления используйте **Залить новый архив** на карточке этого же бота. Не создавайте второй экземпляр: два процесса с одним Telegram-токеном конфликтуют при long polling.

## 7. Важное о файле `.env`

Для Bothost предпочтительно не загружать `.env` в архив, а добавить секреты через раздел **Переменные окружения**. Это безопаснее и соответствует официальной документации. Архив не содержит ключей.
