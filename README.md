# Олег — Telegram-модератор и автоответчик

Бот работает через Telegram long polling, поэтому на FPS.ms нужен постоянный процесс или включённый автоперезапуск контейнера.

## Функции

- удаляет сообщения самого бота;
- удаляет оскорбления, спам, разжигание ненависти и провокации;
- мат сам по себе не считается нарушением;
- индивидуальная лестница: предупреждение → 24 ч → предупреждение → 48 ч → предупреждение → 7 дней → предупреждение → постоянный бан;
- SQLite сохраняет счётчики и активные муты;
- отвечает на сообщения с точным префиксом `ОЛЕГ ОТВЕТ:` через OpenRouter;
- не отвечает чаще 1 раза в 15 секунд и более 10 раз в сутки на пользователя;
- ограничивает вопрос 300 символами;
- на темы 18+, политики и религии отвечает уклончиво, но не молчит;
- все ответы и предупреждения публикуются только в чате, не в канале.

## Важное перед запуском

1. Загрузите `bot.py`, `requirements.txt`, `Dockerfile` и `.env` на FPS.ms.
2. Не публикуйте `.env`, не добавляйте его в Git и не показывайте его содержимое в тикетах/чатах.
3. В `.env` задайте `TELEGRAM_BOT_TOKEN` и `OPENROUTER_API_KEY`.
4. Рекомендуется указать числовой `ALLOWED_CHAT_ID` чата «Психика на минималках Чат». Если оставить пустым, бот будет работать во всех группах, где он является участником.
5. Для определения ID отправьте в чат любое сообщение после запуска и посмотрите запись в логах или используйте Telegram-бота для получения chat id. Не передавайте ID канала вместо ID чата.
6. У бота должны быть права администратора: удаление сообщений, блокировка пользователей и ограничение пользователей.
7. Privacy Mode в BotFather должен быть отключён.
8. Включите persistent storage для `/data`, иначе SQLite-счётчики сбросятся при пересоздании контейнера.

## Docker

```bash
docker build -t oleg-chat-bot .
docker run -d --name oleg-chat-bot --restart unless-stopped --env-file .env -v oleg_bot_data:/data oleg-chat-bot
```

## Без Docker

```bash
python3.11 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Проверка

В чате отправьте:

```text
ОЛЕГ ОТВЕТ: как дела?
```

Код сам тестовое сообщение не отправляет. В Telegram-канал бот ничего не публикует.
